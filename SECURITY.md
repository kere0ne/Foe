# Security Policy

Foe Agent is an early-stage prototype. Authentication, per-user authorization, rate limiting, and comprehensive audit logging are not implemented. Do not deploy it as a public multi-user service.

For local testing, bind the server to `127.0.0.1`. Keep host command execution disabled. Do not expose Docker socket access to untrusted users.

Please do not post secrets, credentials, or sensitive files in issues. Report security concerns privately to the repository owner.
